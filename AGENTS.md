# Pennedal - til AI-værktøjer (fx Codex)

Reglerne for projektet står ét sted: **`CLAUDE.md`**. Læs den helt, før du ændrer noget. Den gælder for alle AI-værktøjer, ikke kun Claude.

Kort:

1. Læs `CLAUDE.md` og derefter `docs/status.md`. Detaljer står i `docs/logbog.md`.
2. Krav 1-10 i `CLAUDE.md` er ufravigelige (fx al elevtekst er HTML, al dansk tekst i `src/content/`, ingen elevdata på en server).
3. Arbejd på en gren og lav en pull request. Kør `npm run tjek` før hver pull request.
4. Ændr aldrig gemmekodens rækkefølge, færdigheds-id'er eller kampmotorens tal uden en test, der viser gammel og ny opførsel.
5. Skriv ærligt, hvad der ikke er testet. Skriv til Henrik på dansk.
